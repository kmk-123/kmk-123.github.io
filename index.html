01 소개

안녕하세요! 저는 외부 API와 실시간 데이터를 다루는 서비스를 좋아하는 개발자입니다. 증권사 API의 실시간 호가로 주문을 체결하고, 여러 AI 모델로 뉴스를 분석해 사용자에게 보여주는 기능을 직접 설계하고 구현했습니다.

  • 주력React · TypeScript · FastAPI
  • 관심사실시간 데이터, AI 연동, 성능 최적화
